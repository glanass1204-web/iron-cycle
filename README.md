# Железный цикл

Программа силы на 13 недель: лёгкие, средние и тяжёлые недели, точные веса для штанги и гантелей, режим «в зале», графики, вес и замеры.

Открыть: https://glanass1204-web.github.io/iron-cycle/

Недели 1–2 бесплатно, полная версия открывается кодом.

## Коды доступа (с 7 ноября 2026)

- Недели 1–2 открыты всем. Остальное открывается кодом, привязанным к номеру телефона (`club150:dev`, вид `XXXX-XXXX`).
- Код — подпись ECDSA P-256 строки `IC1|` + номер телефона, в base64url (86 символов). В `index.html` лежит только открытый ключ `LIC_PUB`; проверка — `verifyCode`, сохранение — `saveLicense`, флаг `LIC_OK` (сохранённому коду доверяем при старте и один раз перепроверяем).
- Старые 8-значные коды (cyrb53 + соль) не принимаются: показывается «Коды старого образца больше не действуют». `cyrb53` и `LIC_SALT` остались только для контрольной суммы переноса данных `IRON1`.
- Режим тренера: 5 нажатий на заголовок карточки «Полная версия» → вставить закрытый ключ тренера (поле `d`, 43 символа). Ключ хранится только в `localStorage` `club150:tkey`. Пароля больше нет.
- **Закрытый ключ тренера никогда не кладётся в репозиторий, в чат или в файлы.** Он не попадает в резервную копию (`NO_COPY`) и в перенос из Safari (`MOVE_SKIP`).
- Оба поля прощают ошибку: код в поле ключа открывает полную версию, ключ в поле кода включает режим тренера.

## Языки

- Русский (основной), украинский и английский: «Ещё» → «Язык», а также кнопки на первом экране.
- Перевод — слой поверх программы: расчёты, история и замены работают на русских названиях. Словари — `i18n/uk.js` и `i18n/en.js` (ключ — русская фраза, числа заменены на `{n}`, вложенный текст — `{s}`).
- Новый текст в программе нужно добавить в оба словаря, иначе он покажется по-русски.

## Правила выпуска

- Каждое изменение — в обе копии: `iron-cycle` (основная ссылка) и `club-150` (старая ссылка, не перенаправлять без проверки).
- При каждом выпуске поднимать `VERSION` в `sw.js`, иначе телефоны не подтянут новую версию.
- Ключи `localStorage` (`club150:*`) не переименовывать: в них данные пользователей.
